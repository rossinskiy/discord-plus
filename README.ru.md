# Discord+

[English](README.md)

Discord+ это мод для приложения Discord на компьютере, со своими плагинами, построенный на фреймворке плагинов Vencord. Установите его и посмотрите список плагинов в настройках Discord, чтобы увидеть, что он добавляет.

Сайт, список плагинов и установка одной командой: [discordplus.karatel.win](https://discordplus.karatel.win/ru/).

Это форк [Vencord](https://github.com/Vendicated/Vencord) под лицензией GPL-3.0, той же, что у Vencord. См. [Авторство и лицензия](#авторство-и-лицензия).

## Что есть

Все плагины Vencord работают как раньше. Кроме них в Discord+ добавлены собственные плагины, среди них:

- **AutoQuest** выполняет принятые вами задания Discord в фоне.
- **Idle Lounge** игровая комната: сад, рыбалка и другое, пока вы отдыхаете.
- **MyProfile** собственные значки и имя в вашем профиле, значки Discord+.
- **LiteMode** снижает нагрузку Discord на процессор, видеокарту и память.
- **AppLock** пароль на вход в Discord, по горячей клавише и после простоя.
- **ScheduledMessages**, **Reminders**, **PersonalStats**, **ChannelNotes**, **ServerCloner**, **BotClient**, **QuietConsole** и другие.

Полный каталог с описанием каждого плагина есть на [сайте](https://discordplus.karatel.win/ru/plugins). Все плагины Discord+ изначально выключены, пока вы их не включите, кроме MyProfile: он встроен и всегда включён.

## Установка

Discord+ ставится из исходников. Нужны Node.js, [pnpm](https://pnpm.io) и Git.

```bash
git clone https://github.com/rossinskiy/discord-plus.git
cd discord-plus
pnpm install
pnpm build
pnpm inject
```

`pnpm inject` запускает установщик и привязывает ваш Discord к этой папке. После этого перезапустите Discord. Если вы изменили код, выполните `pnpm build` и перезапустите Discord, либо нажмите `Ctrl+R`, если правка касалась только кода интерфейса. Изменения основного процесса требуют полного перезапуска.

Не используйте для этого установщики с vencord.dev. Они ставят обычный Vencord, а не Discord+.

## Предупреждение про AutoQuest

Автоматизация заданий противоречит правилам Discord. Другие пользователи сообщают о временных блокировках доступа к заданиям за то, что Discord называет неподлинным выполнением, поэтому риск для вашего аккаунта реален. AutoQuest не обходит капчи и трогает только задания, которые вы приняли сами. Используйте его на аккаунте, который не жалко потерять, или не включайте.

Вообще любой мод клиента противоречит правилам Discord. Вы используете Discord+ на свой риск.

## Если сломался патч после обновления Discord

Discord часто меняет внутренности, и из-за этого перестают работать отдельные патчи. Проверить, какие именно, можно командой:

```bash
pnpm checkPatches
```

Она скачивает свежие файлы Discord и показывает патчи, которые больше не подходят. Ключ `--all` добавляет ленивые части приложения, это дольше. Патчи с текстами вида `#{intl::...}` скрипт пропускает.

## Как это сделано

Discord+ написан с помощью ИИ-ассистента (Claude Code), под руководством и с проверкой автора. Собственные плагины, окно второго аккаунта и бэкенд сделаны так. Возможны шероховатости, поэтому прочитайте код, прежде чем доверять ему что-то важное. Сообщения об ошибках и пулл-реквесты приветствуются.
