Plugins

Eleven plugins written for Discord+, plus the second account window. Every plugin from Vencord still works in the same settings page. All Discord+ plugins start off until you switch them on.

Fun

  • An idle garden that keeps earning while you chat, fishing with a collection of 30 fish, a brick game that plays itself, a fidget board, knife flipping, running in circles, rooftop parkour, and eight calm scenes such as an aquarium, a fireplace and a rainy window.

    Garden 4.32K coins, 3.3 per second
    Fishing Caught a trout and 2 more
    Bricks Level 5, 12 balls
    Illustration, not a screenshot.
    • Open it from the button in the chat bar or with the /lounge command.
    • Progress is saved in a file on your PC, so it survives a reinstall.
    • It is all just games. Nothing in it is sent anywhere.
    Saves data

    • It replaces MessageLogger, so you cannot run both.
    • It only knows what your client saw while it was running.
    • A button in the plugin settings clears it all at once.

Appearance

  • Give yourself badges and a display name that only you see, even ones that look like Discord's own. Discord+ users also get a member number: the lower it is, the earlier they joined. Others with Discord+ see it as a badge on the profile.

    yourname
    Discord+ OG #7, since October 22, 2026
    Display name only you see this one
    Illustration, not a screenshot.
    • The Discord+ badges (Dev, Tester, Supporter, Founder, Bug Hunter, Artist) are handed out by the Discord+ team. You cannot give them to yourself.
    • To show badges it asks the Discord+ server about people whose profiles you look at, which sends their user IDs. You can turn that off in the plugin settings.
    • Joining the member list sends your own user ID once. That is a setting too, and it is on by default once you enable the plugin.
    • Your own badges and display name never leave your PC.
    Saves data
    your PC
    Discord+ server
    optional lookups, they send user IDs

Built in

  • Press Ctrl+Shift+2 while a Discord window is focused. The second account runs in its own window with a separate login, and both stay connected, so messages and notifications arrive on both.

    Ctrl+Shift+2 Account 1 and Account 2
    Both stay connected
    Illustration, not a screenshot.
    • There is nothing to switch on, it is part of Discord+.
    • Only one window is visible at a time, and the second one does not appear in Alt+Tab.
    • The shortcut only works while a Discord+ window is focused. It is never a system-wide hotkey.
    • Closing the second window hides it instead of closing it.
    Saves data
    a separate login on your PC
    Discord+ server
    none
    Risk
