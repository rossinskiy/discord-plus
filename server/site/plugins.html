Plugins

Seven plugins written for Discord+, plus the multi-account window. All of Vencord's own plugins are still available in the same settings page.

Second account window

built inno server needed

Not a plugin, so there is nothing to switch on. Press Ctrl + Shift + 2 while a Discord window is focused.

  • The second account runs in its own window with a separate login, and both accounts stay connected, so messages and notifications arrive on both.
  • Only one window is visible at a time, and the second one does not appear in Alt+Tab.
  • The shortcut only works while a Discord+ window is focused. It is never a system-wide hotkey.
  • Closing the second window hides it instead of closing it.

No plugin matches that search.

MessageArchive

needs your server

Saves edited and deleted messages to your server and shows them in chat, like MessageLogger.

What it does

  • Deleted messages stay visible in chat, marked as deleted.
  • Click the (edited) text on a message to open its edit history.
  • Entries expire after 7 days. A button in the plugin settings clears everything immediately.

Good to know

Replaces MessageLogger. You cannot enable both at once, and enabling one is blocked while the other is on.

NicknameHistory

needs your server

Records changes to usernames, display names and per-server nicknames over time.

What it does

  • Right-click a person and choose View Name History.
  • Works for global display names, not only server nicknames.
  • Only changes your client observed are recorded, starting from when you enable it.

LastSeen

needs your server

Remembers when someone was last seen, and what showed it: going offline, typing or sending a message.

What it does

  • Right-click a person and choose Last Seen.
  • Logs the moment someone leaves online, idle or do not disturb, each message they send, and when they start typing.
  • Typing is logged once per person every 30 seconds, so it does not flood your server.

Good to know

This is not a read receipt. Discord does not give clients that data, and LastSeen only knows what your own client saw while it was running. Someone in invisible mode looks the same as offline.

UserTags

needs your server

Your own tags and a private note on any person, stored on your server.

What it does

  • Right-click a person and choose Tags & Notes.
  • Tags show next to their name in chat. Hover a tag to see the note.
  • Settings has a Browse tagged people button with a filter by tag.

Good to know

Separate from Discord's built-in notes, which stay as they are.

BulkExport

no server needed

Exports the full history of a channel or DM to a JSON file.

What it does

  • Runs locally and saves a file to your computer. No server needed.
  • Long histories take a while because Discord limits how fast messages can be fetched.

AutoLeaveEmptyVC

no server needed

Disconnects you from a voice channel once you are the only human left.

What it does

  • You choose the delay before leaving. The default is 30 seconds.
  • Bots do not count as people.
  • If you join an empty channel and nobody comes, you can stay. It only leaves after someone joined and then left.

AutoQuest

no server neededaccount risk

Completes the Discord Quests you have accepted, in the background, and tries to claim the reward.

What it does

  • Handles play-a-game quests, watch-a-video quests and play-an-activity quests. Stream quests are not supported because they need a real viewer.
  • Checks for new accepted quests every few minutes. Both the check interval and toast messages are settings.
  • Auto-claim is on by default. If Discord asks for a captcha or extra details, the reward is left for you to claim in the Quests tab.

Good to know

Automating quests breaks Discord's rules and has led to account suspensions for some users. Accept the quests yourself first. Use a spare account if you can.
