Установка

Discord+ ставится из исходного кода, а скрипт ниже сделает всё за вас. Это займёт несколько минут.

Требования

  • Windowsпроверено
  • Linuxпроверено на Arch
  • macOSпока не проверено
  • Discordстабильное приложение для компьютера
  • Gitлюбая свежая версия
  • Node.js22 или новее
  • pnpmставится за вас

Не используйте установщики с vencord.dev. Они ставят обычный Vencord, а не Discord+.

Вариант А: одна команда

Скрипт проверяет Git и Node.js, при необходимости ставит pnpm, скачивает Discord+ в %USERPROFILE%\discord-plus (~/discord-plus в macOS и Linux), собирает его и запускает установщик в Discord. Больше он ничего не меняет. Прочитайте его сначала, он короткий: install.ps1 для Windows, install.sh для macOS и Linux.

  1. Запустите установщик

    Windows. Нажмите клавишу Windows, введите PowerShell, нажмите Enter и вставьте:

    PS> irm https://discordplus.karatel.win/install.ps1 | iex

    macOS и Linux. Откройте Терминал и вставьте. Проверено на Linux (Arch), на macOS пока нет. Если не получится, напишите, что он вывел:

    $ curl -fsSL https://discordplus.karatel.win/install.sh | bash

  2. Выберите свой Discord

    Сначала закройте Discord. Когда спросят, какой Discord патчить, выберите стабильный. В macOS и Linux может понадобиться пароль, потому что установщик пишет в папку самого Discord.

  3. Включите плагины

    Запустите Discord, откройте «Настройки», затем «Плагины» и включите нужные плагины Discord+. Все они по умолчанию выключены.

Вариант Б: по шагам

  1. Получите код

    git clone https://github.com/rossinskiy/discord-plus.git cd discord-plus

  2. Установите зависимости

    pnpm install

  3. Соберите

    pnpm build

  4. Добавить в Discord

    Сначала закройте Discord. Когда спросят, выберите свой Discord.

    pnpm inject

  5. Перезапустите Discord

    Откройте «Настройки», затем «Плагины» и включите нужное.

Обновление и удаление

Обновление. Ничего делать не нужно. Пока Discord открыт, Discord+ каждые полчаса проверяет новую версию, скачивает и собирает её и показывает уведомление. Когда оно появится, перезапустите Discord. Если новая версия не собралась, Discord+ вернётся к версии, которая работала. Обновить можно и повторным запуском той же команды.

Удаление. В папке Discord+ выполните pnpm uninject и перезапустите Discord. Он вернётся в обычное состояние.

Если что-то пошло не так

Настройки или окно падают после обновления Discord

Discord что-то изменил внутри приложения. Обновите Discord+ (см. выше) и перезапустите Discord.

Установщик пишет, что не может найти Discord

Полностью закройте Discord, включая значок в трее, и запустите снова. Поддерживается только стабильная версия Discord для компьютера.

Я поставил установщик с vencord.dev

Он ставит обычный Vencord, а не Discord+. Используйте шаги с этой страницы.

Другая проблема

Создайте обращение на GitHub и опишите, что вы делали и что произошло. При сбое больше всего поможет красная ошибка из консоли (Ctrl+Shift+I).
