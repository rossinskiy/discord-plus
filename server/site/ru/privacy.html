Этот сайт

Этот сайт состоит из статичных страниц. На нём нет аккаунтов, форм, аналитики, рекламы, сторонних скриптов, шрифтов и трекеров. Он не устанавливает cookie.

Локальное хранилище браузера держит на вашем устройстве два небольших значения: выбранную светлую или тёмную тему и то, закрыли ли вы уведомление внизу страницы. Они никогда не покидают ваш браузер.

Как и любой веб-сервер, этот может вести стандартные журналы доступа (ваш IP-адрес, запрошенная страница, время и user agent браузера) для безопасности и поиска неисправностей. Эти журналы никому не передаются и не используются для составления профилей.

Клиент Discord+

Discord+ работает на вашем компьютере. Кроме сервиса бейджей MyProfile, описанного ниже, он ничего не отправляет автору и в сервисы автора.

Плагин MyProfile показывает бейджи Discord+ в профилях других людей. Для этого он спрашивает у сервера Discord+, у кого из просматриваемых вами пользователей есть бейдж. В запросе передаются Discord ID этих пользователей, а сервер видит ваш IP-адрес, как любой веб-сервер. Больше в этих запросах ничего не отправляется: ни ваши сообщения, ни данные аккаунта. Сервер хранит только список, какому ID какой бейдж выдан. Стандартные журналы доступа, описанные выше, могут содержать эти запросы с ID в адресе. MyProfile встроенный плагин и всегда включён, поэтому отключить этот запрос нельзя. Ваши собственные бейджи и отображаемое имя остаются на вашем компьютере.

Discord+ также обновляется сам. Пока Discord открыт, примерно каждые полчаса он спрашивает у GitHub, есть ли в репозитории новая версия, и скачивает её. GitHub видит ваш IP-адрес, как любой сайт, больше о вас ничего не отправляется. Обновление приходит из репозитория Discord+ на GitHub, а не с сервера Discord+.

Тот же плагин вносит вас в список пользователей Discord+. При запуске Discord+ ваш Discord ID отправляется на сервер, и сервер хранит его вместе с номером участника и датой вступления. Другие пользователи Discord+ видят этот номер и дату бейджем в вашем профиле. Больше ничего не отправляется. Отключить это нельзя. Чтобы вас убрали из списка, откройте issue на GitHub, и запись будет удалена. При следующем запуске Discord+ вас добавят снова, так что единственный способ не быть в списке: не пользоваться Discord+.

Четыре плагина (MessageArchive, NicknameHistory, LastSeen и UserTags) хранят данные в локальном хранилище браузера (IndexedDB) только на вашем компьютере. В данных могут быть тексты сообщений, ссылки на вложения, ID пользователей и каналов, имена и ники, смены статуса и ваши теги и заметки. Ничего из этого никуда не отправляется, а очистка в настройках плагина или удаление Discord+ стирает данные насовсем.
