Discord+

A free fork of Vencord for the Discord desktop app. Every Vencord plugin still works, and eleven more were written for it: quests on autopilot, a game lounge, your own profile badges and a lighter Discord. What it saves stays on your PC.

Install

One command, in PowerShell on Windows:

irm https://discordplus.karatel.win/install.ps1 | iex

Needs Git and Node.js 22 or newer. It asks which Discord to patch.

Client mods break Discord's rules, and AutoQuest is the riskiest part. Read the warning.

Storage Configuration

Where each plugin keeps its data, and what it sends out. There is no account and no tracking. The only contact with the Discord+ server is the MyProfile lookup, which sends user IDs, and you can switch it off.

Warning

Client mods, Discord+ included, go against Discord's terms of service. AutoQuest is the riskiest part: other users report temporary Quest suspensions for what Discord calls inauthentic quest completion. Use it on an account you can afford to lose, or leave that plugin off. You use Discord+ at your own risk.

Questions

Is Discord+ safe to use?

It is open source, so every line can be read, and nothing it saves leaves your PC apart from the MyProfile lookups in the table above.

Client mods, Discord+ included, go against Discord's terms of service and Discord may act against accounts that use them. AutoQuest raises that risk. You use Discord+ at your own risk.

Which systems does it run on?

It is tested on Windows with the stable Discord desktop app. Installing from source on macOS or Linux may work, but nothing there has been tested.

Do I have to remove Vencord first?

You do not need to uninstall it by hand. The installer points Discord at Discord+ instead. Discord+ reads the same settings folder as Vencord, so your existing Vencord settings carry over.

What is the member number?

If MyProfile is on, Discord+ gives your account a number in order of arrival and records the date you joined. Other Discord+ users see it as a badge on your profile. It is a setting you can turn off, and then nothing is sent.

What does it cost?

Nothing. It is free software under the GNU General Public License v3.0.

How do I update or remove it?

Discord+ updates itself. While Discord is open it checks for a new version every half hour, downloads and builds it, and shows a notice. You restart Discord once and you are on the new version.

To remove it, run pnpm uninject inside the Discord+ folder. The install page has the details.
