Open source Discord client mod

Keep deleted messages. Run two accounts. Let Discord do the chores.

Discord+ is a free fork of Vencord for the Discord desktop app. It adds its own plugins, a second-account window and an optional backend that you host yourself, so your data stays on your server.

Install from source Browse plugins GitHub 
$ git clone https://github.com/rossinskiy/discord-plus.git
$ cd discord-plus
$ pnpm install
$ pnpm build
$ pnpm inject

Needs Node.js 22 or newer, pnpm and Git. Restart Discord after injecting. Full guide

What Discord+ adds

Everything from Vencord keeps working. These are the parts written for Discord+.

Two accounts, one keystroke

Press Ctrl + Shift + 2 inside Discord to flip between your accounts. The second account has its own login and window. Both stay connected and keep receiving messages, and the second window never shows in Alt+Tab.

Message archive

Edited and deleted messages are saved locally on your own computer and shown right in the chat, the way MessageLogger shows them. Entries expire after 7 days, or earlier when you clear them from the plugin settings.

Tags and private notes on people

Give anyone your own tags and a note that only you can see. Tags appear next to the person's name in chat, and you can filter everyone you have tagged by tag.

Quests on autopilot

AutoQuest completes the Discord Quests you have accepted and tries to claim the reward. It breaks Discord's rules and puts your account at risk, so read the warning first.

Your data stays on your server

Four plugins keep history: MessageArchive, NicknameHistory, LastSeen and UserTags. They write to a small server that you run. It is a single Node.js app with a SQLite file, and there is no account and no third party involved.

Discord+ on your PC

The plugins watch what your own client sees: edits, deletes, name changes, presence.

Your server

Express and SQLite behind HTTPS. Every request needs your secret token.

Only you

History is available while your PC is off, but it only holds what your client saw while it was running.

Read this before you install

Client mods, Discord+ included, go against Discord's terms of service. AutoQuest is the riskiest part: other users report temporary Quest suspensions for what Discord calls inauthentic quest completion. Use it on an account you can afford to lose, or leave that plugin off. You use Discord+ at your own risk.

Questions

Is it free?

Yes. Discord+ is released under the GNU General Public License v3.0, the same license as Vencord. You can read, change and share the code.

Do I need my own server?

Only for MessageArchive, NicknameHistory, LastSeen and UserTags. BulkExport, AutoLeaveEmptyVC, AutoQuest and the second-account window work without one.

Can I get banned?

It is possible. Any client mod breaks Discord's terms of service, and automating Quests carries extra risk. I cannot give you odds, so decide based on how much the account matters to you.

Which systems does it run on?

It is built and tested on Windows with the stable Discord desktop app. Other desktop systems may work because the installer comes from Vencord, but they are untested. There is no mobile version.

Can I run it next to Vencord?

No. Discord+ replaces the Vencord loader, so you use one or the other. Vencord's own plugins are included.

How do I update?

Run git pull and pnpm build in the project folder, then restart Discord. After a Discord update, pull again if something breaks.

Is it affiliated with Discord or Vencord?

No. It is an independent fork. Vencord is made by Vendicated and contributors, and Discord is a trademark of Discord Inc.
