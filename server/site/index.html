Plugins

Every one starts off. You switch on what you want in Discord's settings.

  • AutoQuest Finishes the Discord Quests you have accepted and tries to claim the reward.Risky
  • Idle Lounge A lounge inside Discord for when you want to do nothing.
  • MyProfile Your own badges and display name, and Discord+ badges on other people.
  • LiteMode Makes Discord lighter on CPU, GPU and RAM.
  • Reminders Remind yourself about a message or anything else.
  • MessageArchive Keeps edited and deleted messages visible in chat.
  • Second account window Flip between two Discord accounts with one shortcut.Built in

Warning

Client mods, Discord+ included, go against Discord's terms of service. AutoQuest is the riskiest part: other users report temporary Quest suspensions for what Discord calls inauthentic quest completion. Use it on an account you can afford to lose, or leave that plugin off. You use Discord+ at your own risk.

Questions

Is Discord+ safe to use?

It is open source, so every line can be read, and nothing it saves leaves your PC apart from the MyProfile lookups in the table above.

Client mods, Discord+ included, go against Discord's terms of service and Discord may act against accounts that use them. AutoQuest raises that risk. You use Discord+ at your own risk.

Which systems does it run on?

It is tested on Windows with the stable Discord desktop app. It also works on Linux (tested on Arch with the official Discord package). The macOS installer exists but has not been tested yet, so open an issue if it breaks.

Do I have to remove Vencord first?

You do not need to uninstall it by hand. The installer points Discord at Discord+ instead. Discord+ reads the same settings folder as Vencord, so your existing Vencord settings carry over.

What is the member number?

MyProfile is built in and always on, so Discord+ gives your account a number in order of arrival and records the date you joined. Other Discord+ users see it as a badge on your profile.

What does it cost?

Nothing. It is free software under the GNU General Public License v3.0.

How do I update or remove it?

Discord+ updates itself. While Discord is open it checks for a new version every half hour, downloads and builds it, and shows a notice. You restart Discord once and you are on the new version.

To remove it, run pnpm uninject inside the Discord+ folder. The install page has the details.

Why did a plugin stop working after a Discord update?

Discord changes its inner code often, and a plugin that hooks into it can break for a few days. Fixes come out through the same automatic update, so a restart of Discord is usually all you need. If it stays broken, open an issue on GitHub and name the plugin.

Which quests does AutoQuest finish?

It finishes the ones you accepted yourself: watch a video, play a game on desktop and play an activity. Quests that ask you to reach a goal inside an activity cannot be done from the client, so those you play by hand. If Discord asks for a captcha when you claim a reward, claim it in the Quests tab.

Are the plugins switched on right away?

No. Every Discord+ plugin is off until you switch it on in the plugin list in Discord's settings. The only exception is MyProfile, which is built in and always on.
