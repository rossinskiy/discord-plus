Privacy policy

Last updated November 15, 2026

This website

This website is a set of static pages. It has no accounts, no forms, no analytics, no advertising and no third-party scripts, fonts or trackers. It sets no cookies.

Your browser's local storage keeps two small values on your device: your light or dark theme choice, and whether you dismissed the notice at the bottom of the page. They never leave your browser.

Like any web server, this one may keep standard access logs (your IP address, the page requested, the time and your browser's user agent) for security and troubleshooting. These logs are not shared or used for profiling.

The Discord+ client

Discord+ runs on your own computer. Apart from the MyProfile badge service described below, it does not send anything to the author or to any service run by the author.

The MyProfile plugin can show Discord+ badges on other people's profiles. To do that it asks the Discord+ server which of the users you look at have a badge. The request contains the Discord user IDs of those users, and the server sees your IP address like any web server does. Nothing else is sent in these lookups: not your messages and not your account details. The server stores only a list of which user IDs were given which badge. The standard access logs described above can include these requests, with the IDs in the address. MyProfile is a built-in plugin that is always on, so the lookup cannot be turned off. Your own badges and display name stay on your computer.

Discord+ also updates itself. While Discord is open it asks GitHub, about every half hour, whether the repository has a newer version, and downloads it when there is one. GitHub sees your IP address like any website, and nothing else about you is sent. The update comes from the Discord+ repository on GitHub, not from the Discord+ server.

The same plugin puts you on the Discord+ user list. When Discord+ starts, your own Discord user ID is sent to the server, and the server stores it together with a member number and the date you joined. Other Discord+ users can see that number and date as a badge on your profile. Nothing else is sent. This cannot be turned off. To be taken off the list, open an issue on GitHub and the entry will be deleted. You are added again the next time Discord+ starts, so the only way to stay off the list is not to use Discord+.

Four plugins (MessageArchive, NicknameHistory, LastSeen and UserTags) keep their data in your local browser storage (IndexedDB), on your own computer only. The data can include message contents, attachment links, user and channel IDs, names and nicknames, presence changes and your own tags and notes. None of it is sent anywhere, and clearing it from the plugin settings or uninstalling Discord+ removes it for good.

Discord

When you use Discord with Discord+, Discord's own terms and privacy policy still apply to your account and your data.
