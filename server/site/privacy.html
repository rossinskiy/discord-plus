Privacy policy

Last updated October 17, 2026

This website

This website is a set of static pages. It has no accounts, no forms, no analytics, no advertising and no third-party scripts, fonts or trackers. It sets no cookies.

Your browser's local storage keeps two small values on your device: your light or dark theme choice, and whether you dismissed the notice at the bottom of the page. They never leave your browser.

Like any web server, this one may keep standard access logs (your IP address, the page requested, the time and your browser's user agent) for security and troubleshooting. These logs are not shared or used for profiling.

The Discord+ client

Discord+ runs on your own computer. By itself it does not send anything to the author or to any service run by the author.

Four plugins (MessageArchive, NicknameHistory, LastSeen and UserTags) send data to a server address that you enter in their settings. That server is one that you run, and the data goes only there. The data can include message contents, attachment links, user and channel IDs, names and nicknames, presence changes and your own tags and notes. You control that server and decide how long data is kept.

The server at this domain

The server behind this domain is the author's own instance for personal use. It is not a public service, it requires a private token and it does not accept accounts or data from other people. If you self-host, your server holds your data and this policy does not apply to it.

Discord

When you use Discord with Discord+, Discord's own terms and privacy policy still apply to your account and your data.
