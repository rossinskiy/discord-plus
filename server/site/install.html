Install

Discord+ is installed from source, and the script below does the typing for you. It takes a few minutes.

Requirements

  • SystemWindows (tested)
  • Discordstable desktop app
  • Gitany recent version
  • Node.js22 or newer
  • pnpminstalled for you

Do not use the installers on vencord.dev. They install stock Vencord, not Discord+.

Option A: one command

The script checks Git and Node.js, installs pnpm if needed, downloads Discord+ into %USERPROFILE%\discord-plus, builds it and runs the Discord installer. It changes nothing else. Read it first, it is short.

  1. Run the installer

    Press the Windows key, type PowerShell, press Enter, and paste:

    PS> irm https://discordplus.karatel.win/install.ps1 | iex

  2. Pick your Discord

    Close Discord first. When it asks which Discord to patch, choose the stable one.

  3. Switch plugins on

    Start Discord, open Settings, then Plugins, and switch on the Discord+ plugins you want. They all start off.

Option B: step by step

  1. Get the code

    PS> git clone https://github.com/rossinskiy/discord-plus.git cd discord-plus

  2. Install the dependencies

    PS> pnpm install

  3. Build it

    PS> pnpm build

  4. Add it to Discord

    Close Discord first. Pick your Discord when asked.

    PS> pnpm inject

  5. Restart Discord

    Open Settings, then Plugins, and switch on what you want.

Update and remove

Update. You do not have to do anything. Discord+ checks for a new version every half hour while Discord is open, downloads it, builds it and shows a notice. Restart Discord when it appears. If a new version fails to build, Discord+ goes back to the version that worked. Running the one command again also updates it.

Remove. Inside the Discord+ folder run pnpm uninject and restart Discord. It goes back to normal.

If something goes wrong

Settings or a window crashes after a Discord update

Discord changed something inside the app. Update Discord+ (see above) and restart Discord.

The installer says it cannot find Discord

Close Discord completely, including the tray icon, then run it again. Only the stable Discord desktop app is supported.

I installed the installer from vencord.dev

That one installs stock Vencord, not Discord+. Use the steps on this page instead.

Something else is wrong

Open an issue on GitHub and say what you did and what happened. A crash helps most with the red error from the console (Ctrl+Shift+I).
