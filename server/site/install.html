Install

Discord+ is installed from source. It takes a few minutes and needs a terminal.

The client

You need Node.js 22 or newer, pnpm, Git and the stable Discord desktop app. It is tested on Windows. Do not use the installers on vencord.dev, because they install stock Vencord instead of Discord+.

  1. Get the code
    git clone https://github.com/rossinskiy/discord-plus.git
cd discord-plus
  2. Install dependencies
    pnpm install
  3. Build
    pnpm build
  4. Inject it into Discord

    This points your Discord at the project folder. Close Discord first if the installer asks you to.

    pnpm inject
  5. Restart Discord

    Open Settings and look for the Discord+ entries. Plugins are off until you enable them in the plugin list.

Update

git pull
pnpm install
pnpm build

Then restart Discord. Changes that only touch the interface can be picked up with Ctrl + R, but a full restart is safer.

Uninstall

pnpm uninject

Restart Discord afterwards and it goes back to normal.

If something does not work

  • Settings or a window crashes after a Discord update. Discord changed something inside the app. Pull the latest code and rebuild, as shown above.

Still stuck? Open an issue on GitHub.
