Install

Discord+ is installed from source. It takes a few minutes and needs a terminal.

The client

You need Node.js 22 or newer, pnpm, Git and the stable Discord desktop app. It is tested on Windows. Do not use the installers on vencord.dev, because they install stock Vencord instead of Discord+.

  1. Get the code
    git clone https://github.com/rossinskiy/discord-plus.git
cd discord-plus
  2. Install dependencies
    pnpm install
  3. Build
    pnpm build
  4. Inject it into Discord

    This points your Discord at the project folder. Close Discord first if the installer asks you to.

    pnpm inject
  5. Restart Discord

    Open Settings and look for the Discord+ entries. Plugins are off until you enable them in the plugin list.

Update

git pull
pnpm install
pnpm build

Then restart Discord. Changes that only touch the interface can be picked up with Ctrl + R, but a full restart is safer.

Uninstall

pnpm uninject

Restart Discord afterwards and it goes back to normal.

The server (optional)

Only MessageArchive, NicknameHistory, LastSeen and UserTags need it. You can skip this section if you do not use them. You need a machine that is always on, such as a small VPS, with Node.js installed.

  1. Copy the server folder to the machine

    It is the server folder in the repository. Run this inside it:

    npm install
  2. Choose a secret token

    Make a long random string. Copy ecosystem.config.example.cjs to ecosystem.config.cjs and put the token in ARCHIVE_TOKEN. Keep that file private.

  3. Start it

    With pm2, or plain Node:

    pm2 start ecosystem.config.cjs
# or: ARCHIVE_TOKEN=your-token node server.js

    It listens on port 8790 on localhost only.

  4. Put it behind HTTPS

    Discord only lets plugins call HTTPS addresses. A Cloudflare Tunnel or a reverse proxy such as Caddy or nginx works. Point your domain at http://localhost:8790.

  5. Tell the plugins where it is

    In Discord, open the settings of MessageArchive and enter your server URL and the token. NicknameHistory, LastSeen and UserTags use the same token automatically unless you give them their own.

If something does not work

  • Server responded with 401. The token is empty or does not match ARCHIVE_TOKEN on the server.
  • Failed to fetch. Check the server URL, that it uses https, and that the server is running.
  • Settings or a window crashes after a Discord update. Discord changed something inside the app. Pull the latest code and rebuild, as shown above.

Still stuck? Open an issue on GitHub.
